# Example data files

This folder contains fictitious examples only.

- `birthday_reminder_management_example_en.xlsx` — English example
- `sistema_recordatorios_cumpleanos_ejemplo_es.xlsx` — Spanish example

The examples show both the management tables and a fictitious birthday-source sheet so readers can understand the expected structure without access to any production data.

The Drive URLs use non-functional placeholder IDs and the email addresses use `example.org`.
