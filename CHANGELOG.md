# Changelog

All notable public changes to this repository will be documented here.

This changelog begins with the first public portfolio release and does not attempt to reconstruct the private development history that existed before publication.

## 1.0.0 — Initial public portfolio release

Included capabilities:

- daily birthday-date checking;
- personal birthday-card delivery by email;
- Drive-hosted inline images;
- monthly birthday announcement;
- BCC recipient handling;
- configurable monthly exclusions;
- administrative delivery confirmation;
- Script Properties configuration;
- English and Spanish example workbooks;
- sanitized public documentation.
